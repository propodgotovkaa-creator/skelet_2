# Нашествие скелетов

Детская браузерная игра для чтения слогов: чтение вслух с педагогом → шесть скелетов → следующий раунд. Без регистрации, микрофона и внешних библиотек. HTML, CSS, JavaScript и Canvas. Все изображения находятся внутри проекта.

## Запуск и GitHub Pages

Откройте `index.html` или запустите любой статический HTTP-сервер из папки игры.
В GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
После завершения публикации адрес игры: `https://propodgotovkaa-creator.github.io/skelet_2/`.

## Встраивание в Genially

После включения GitHub Pages используйте опубликованный HTTPS-адрес или iframe:

```html
<iframe src="https://propodgotovkaa-creator.github.io/skelet_2/"
  title="Нашествие скелетов" width="1280" height="720"
  style="border:0;aspect-ratio:16/9;width:100%" allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Игра сохраняет пропорции 16:9; в узком окне появляются свободные поля. Для интерактивной доски лучше полноэкранный альбомный режим.

## Управление

- Выберите буквы, открытые / закрытые / смешанные слоги, количество и скорость.
- Педагог нажимает «Прочитал! К бою!» после чтения ребёнком.
- Мышь или касание: прицеливание и один выстрел. Клавиатура: стрелки и пробел.
- Пауза: кнопка Ⅱ или Escape. При уходе со страницы бой автоматически приостанавливается.
- Кнопка домика возвращает к настройкам.
- После проигрыша сохраняются номер раунда и настройки; перед повторной атакой снова показываются слоги.

В волне всегда шесть разных персонажей: пират, Пиппа, волшебник, Луна, лесной озорник и Тито. Скорость не увеличивается между раундами. До первого достигшего игрока скелета: медленная — около 22 секунд, обычная — 13 секунд, быстрая — 8 секунд (без учёта перехода после чтения). На одного скелета нужно одно попадание. Никаких скримеров или жестоких эффектов.

## Чтение

Всего 10 гласных и 20 согласных. Учебный фильтр исключает сочетания ЖЫ/ШЫ/ЧЫ/ЩЫ, ЖЯ/ШЯ/ЧЯ/ЩЯ, ЖЮ/ШЮ/ЧЮ/ЩЮ, ЖЭ/ШЭ/ЧЭ/ЩЭ и ЦЯ/ЦЮ/ЦЁ/ЦЭ. Дополнительно не используются редкие для начального чтения ГЫ/КЫ/ХЫ. Исключения в заимствованиях и именах собственных намеренно не включены. ЦЫ, ЦИ, ЖИ, ШИ, ЧА, ЩА, ЧУ, ЩУ сохранены. Правила применяются и к открытой части смешанного режима. Обратные сочетания вроде ЫЖ не запрещаются: это другой порядок букв. Источник: [Грамота.ру — гласные после шипящих и ц](https://gramota.ru/biblioteka/spravochniki/pravila-russkoy-orfografii-i-punktuatsii/glasnye-posle-shipyashchikh-i-ts). Число элементов ограничено доступными уникальными сочетаниями. Внутри списка нет повторов. Qanelas используется, если установлен; иначе применяется Arial для слогов и Trebuchet MS для интерфейса.

## Графика и реализация

Исходные персонажи Луна, Пиппа и Тито взяты из предыдущего пользовательского проекта `propodgotovkaa-creator/skelet`. Новые персонажи и лес созданы встроенным ImageGen. См. `ARTWORK.md`. Спрайты разделены на голову, корпус, таз, руки и ноги и анимируются относительно суставов. Перспективная проекция одновременно меняет размер, положение по горизонтали и положение ступней на дорожке. Canvas учитывает плотность пикселей экрана (до 3840 пикселей по ширине). У Луны и трёх новых персонажей дополнительно анимируются локти и колени. Используется объёмный бластер с прозрачностью. Эффекты и движение обновляются единственным requestAnimationFrame; переходы очищают временные объекты. Web Audio создаёт короткие звуковые эффекты после действия пользователя.

## Проверка

Проверены генерация и уникальность слогов, пустой и ограниченный набор букв, обязательное чтение, промахи, шесть попаданий, победа, следующий раунд, пауза, проигрыш, повтор и выход в меню. Выполнена визуальная проверка в браузере и проверка отсутствия ошибок в консоли. Реальное встраивание в проект Genially требует опубликованного адреса и проверяется после настройки Pages.

Автоматическая проверка: `node tests/game.test.cjs`. Тесты проходят по всем 200 парам букв × 3 режима и проверяют время подхода 22/13/8 секунд.
